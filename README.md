# 2024-Cybersecurity-Hackathon-Competition_Antifragile
## About The Project

This is the 2024-Cybersecurity Hackathon Contest_Antifragile's ANTI* project developed by the 'Antifragile' team.

이는 'Antifragile' 팀이 개발한 2024-사이버보안 해커톤 경연대회_Antifragile의 ANTI* 프로젝트입니다.

*** ANTI* is a follow-up study based on the research and development conducted in the [WHS_2nd_ANTIFRAGILE](https://github.com/swyoo1121/WHS_2nd_ANTIFRAGILE) repository. Based on the tools and methods developed in previous projects, we aim to further strengthen cybersecurity threat and anti-forensic detection and prevention. As the team advanced to the finals for this project, this repository was used to further develop based on the accumulated knowledge and code base of previous projects.

ANTI*는 [WHS_2nd_ANTIFRAGILE](https://github.com/swyoo1121/WHS_2nd_ANTIFRAGILE)  레포지토리에서 진행된 연구와 개발을 기반으로 한 후속 연구편입니다. 이전 프로젝트에서 개발된 도구와 방법을 바탕으로 사이버보안 위협 및 안티포렌식 탐지 및 예방을 더욱 강화하고자 합니다. 본 프로젝트는 팀이 본선에 진출하게 되면서, 이전 프로젝트의 축적된 지식과 코드베이스를 바탕으로 더욱 발전시키기 위해 이 레포지토리를 활용하게 되었습니다.

**1 ) 디지털 포렌식 정의와 디지털 포렌식 증거 분석 현황.**

    - 디지털 포렌식 분야는 1970년대부터 기술 발전과 함께 진화해 왔다. 오늘날 사이버 범죄의 증가로 인해 그 중요성이 더욱 주목받고 있다.

    - 디지털 포렌식 : 
      - 디지털 증거물을 수사에 활용
      - 디지털 증거물의 증거 능력을 향상시키기 위한 과학 수사기법을 총칭하는 용어
    - 안티포렌식 : 
      - 자신에게 불리한 증거를 훼손하거나 차단하는 행위 등 중요한 증거를 찾기 어렵게 만드는 기법

      - 데이터 파괴, 은닉, 수정, 흔적 최소화 등이 안티포렌식 행위로 분류됨.

      - 우리나라에서도 안티포렌식 기술은 빠르게 발전하면서 수사기관의 수사 진척에 어려움을 주는 등 심각한 문제로 대두되고 있다. 경찰에서 통용되는 안티포렌식 기법으로는 △데이터 파괴(Destruction) △데이터 암호화(Encryption) △데이터 은닉(Hiding) △데이터 조작(Manipulation) △풋프린트 최소화(Minimizing the Footprint) △분석 시간 증가(Reducing analyzability) 등이 있다.

#### 나. 개발 목표 및 주요 내용

**1 ) 개발목표**

  효율적으로 안티포렌식 행위를 탐지할 수 있는 푸시 버튼 포렌식(PBF) 소프트웨어를 개발하고자 한다. 이는 복잡한 분석 기능을 자동화하여 전문가의 작업을 돕는 것을 목표로 한다. 특히 안티포렌식 행위를 효과적으로 탐지하기 위한 알고리즘을 개발하여 제안한다. 데이터 삭제, 은닉, 변조 기술 등의 대표적인 안티포렌식 행위를 탐지하는 소프트웨어를 구축하는 것을 목표로 한다.
  
&emsp;**1-1) 안티포렌식 행위 탐지 결과 및 제공**
   - 탐지된 안티포렌식 행위의 결과를 한눈에 확인할 수 있도록 종합적인 결과 화면을 제공한다. 사용자는 이를 통해 각 기법별 탐지 여부를 손쉽게 파악할 수 있으며, 탐지된 사례를 일목요연하게 정리된 테이블 형식으로 제공받을 수 있다.

&emsp;**1-2) 안티포렌식 행위 탐지 결과에서 기법별 검색 기능 제공**
   - 탐지된 결과 내에서 특정 안티포렌식 기법(예: 데이터 삭제, 은닉 등)을 기준으로 검색할 수 있는 기능을 지원한다. 이를 통해 사용자들은 필요한 정보를 빠르게 찾을 수 있으며, 맞춤형 분석이 가능하다.

&emsp;**1-3) 이미징 파일, $J 파일의 Evidene Tree, Properties 제공**
   - 입력된 이미징 파일 및 $J 파일에 대한 상세 정보를 시각화된 Evidence Tree 구조로 제공한다. 사용자는 각 파일의 메타데이터(Properties)와 구조를 직관적으로 확인할 수 있어, 분석 과정에서 더욱 효율적인 탐색이 가능하다.

&emsp;**1-4) 탐지결과 추가적인 디테일 탐지 제공**
   - 탐지 결과 화면에서 특정 파일명을 클릭하면, 해당 파일의 Hexa View 화면으로 자동 연결된다. 
   - 이를 통해 사용자는 탐지된 안티포렌식 행위와 관련된 세부 데이터를 정확히 확인할 수 있다. 예를 들어, $J 파일의 특정 로그 기록이나 변조 흔적을 Hexa View에서 시각적으로 확인 가능하다.

&emsp;**1-5) 친화적이고 편리한 GUI 제공**
   - 잘 알려지고 많이 상용화 되고 있는 도구보다 도킹기능이 뛰어남.
   - 유연한 도킹기능으로 도구 내외에서 사용자가 원하는 인터페이스로 맞춤형 가능.
   - 복잡하지 않고 간결하고, 깔끔하여 도구 사용법이 일반사용자들도 접근하기 매우 쉬움.

&emsp;**1-6) 디지털 포렌식 효율성 향상**
   - 탐지 속도와 정확도를 높이고, 분석 결과를 체계적으로 정리하여 보고할 수 있는 시스템 구현.
   - 탐지 결과를 다양한 시각적 형태로 제공해 분석가가 쉽게 결과를 해석할 수 있도록 지원.

**2 ) 주요내용**

&emsp;**2-1) 안티포렌식 탐지 기능**
   - 안티포렌식 탐지 알고리즘: 데이터 삭제, 은닉, 변조 등의 행위를 탐지하고 보고하는 알고리즘 개발.
   - 기법별 탐지 및 검색 기능: 특정 안티포렌식 기법 탐지 결과를 검색하고 분석할 수 있는 기능.
   - 이미징 파일 분석: $J 파일 등에서 로그와 아티팩트를 정밀 분석해 삭제 및 변조 기록 탐지.
   - Hexa View 제공: 탐지된 파일의 상세 정보를 헥사 뷰로 제공하며 클릭 한 번으로 탐지 내용을 확인.

&emsp;**2-2) 주요 알고리즘**
   - 단순 삭제 탐지: $J 파일의 Reason Flag 분석을 통한 파일 삭제 탐지.
   - 와이핑 탐지: Eraser와 같은 와이핑 툴 사용 흔적 분석 및 반복 구조 탐지.
   - 데이터 변조 탐지: 파일 시그니처 비교를 통한 변조 여부 확인 및 복구 알고리즘.
   - 데이터 은닉 탐지: 확장자 변경, 스와핑 등 숨겨진 데이터를 탐지.

&emsp;**2-3) GUI 및 사용자 경험**
   - 도킹 기능: 자유로운 인터페이스 구성으로 사용자 맞춤형 환경 제공.
   - 간결한 디자인: 복잡하지 않고 직관적인 화면 구성으로 사용법을 쉽게 이해할 수 있도록 설계.

&emsp;**2-4) 예상 성과**
   - 안티포렌식 탐지 효율화: 디지털 포렌식 분석 시간을 단축하고 탐지 성공률 향상.
   - 전문가 도구로서의 활용 가능성 증대: 기존 상용 도구와의 차별성을 기반으로 포렌식 시장에서 경쟁력 확보.
   - 디지털 포렌식 역량 강화: 안티포렌식 기법 발전에 대응할 수 있는 포렌식 역량 강화 및 수사 지원.

#### 다. 세부내용

> 더 자세한 기능 설명은 개발결과의 기능설명 참고

  **1 ) 안티포렌식 기법**
  디지털 정보를 분석하지 못하도록 삭제하는 기술이다. 아래와 같은 기법이 존재한다.
   - 원 데이터 파괴 : 기업 내규를 위반한 사람들이 죄를 감추기 위해 데이터를 조작하거나 위장 등.
   - 데이터 암호화 : 뛰어난 암호 공격으로도 풀 수 없는 특별한 암호 알고리즘을 사용.
   - 데이터 은닉 : 확장자명을 바꾸거나 스와핑하고, 한글 파일을 이미지 파일로 또는 텍스트 파일을 동영상 파일로 바꾸는 등.
   - 난독화 방법 : 글자 배열을 섞거나 글자 사이에 다른 부호를 첨부한다든가 등의 방식을 통해 데이터를 읽지 못하게 함.
   - 데이터 피난 : 사법 권한이 미치지 않는 해외 서버에 데이터를 저장하고 다크사이트나 다크웹 등을 이용.


  **2 ) 단순삭제 알고리즘 구체적 설명**

#### 나. 기능설명

**1 ) Evidence Tree, Properties**

&emsp;**1-1) Evidence Tree**
   - 디스크 구조와 파일 목록을 계층적으로 시각화하여 사용자가 탐색 가능.
   - 각 파일의 이름과 크기를 표시하며, 크기가 없는 항목(N/A)은 특수 파일이나 숨겨진 데이터일 가능성이 있음.

&emsp;**1-2) Properties**
  - Evidence Source: 파일 경로와 증거의 유형(Forensic Disk 등)을 표시.
  - Disk: 드라이브 정보 제공, 바이트 크기 및 섹터 수를 포함.
  - Image: 이미지 유형(예: Raw(dd))을 표시하여 포렌식 이미징 방식 설명.




**2 ) Detection Result**

&emsp;&emsp;**2-1) 단순삭제**
  - $UsnJrnl/$J파일 입력
  - USN Journal 파일을 읽어 각 레코드를 분석하고, 파일 삭제 이벤트를 탐지.
  - 시스템 파일 및 디렉토리는 필터링하며, 삭제 플래그를 기반으로 완전 삭제된 파일을 식별.
  - 탐지된 파일의 이름, 삭제 유형, 삭제 타임스탬프를 출력하며, 분석 결과는 필요 시 별도로 저장.

&emsp;&emsp;**2-2) 와이핑**
  - $UsnJrnl/$J파일 입력
  - 지정된 파일을 읽어 청크 단위로 Excel 파일 시그니처와 J 레코드 시그니처를 검색.
  - 예를 들어, Excel 시그니처가 이전에 유효한 J 레코드가 존재하다고 한다면, 다음 로그 레코드에서 일치하지 않는 기록이 발견되면 와이핑 흔적으로 판단.
  - 와이핑 흔적 발견 여부와 관련된 메시지를 출력하여 파일 상태를 보고.

&emsp;&emsp;**2-3) 데이터 위변조**
  - 변조한 파일 폴더, 복구할 파일 폴더 입력
  - 파일의 헤더와 푸터를 확인하여 파일 형식을 탐지하고, 확장자와 일치 여부 검사.
  - 푸터 이후 숨겨진 데이터를 탐지하여 복구 가능 여부 확인 후 별도 파일로 저장.
  - JPEG 파일의 SOS 마커 손상 여부를 검증하며, 손상된 경우 복구 데이터를 생성.
  - 탐지 결과로 위변조 유형, 복구 파일 경로, 타임스탬프를 출력하여 파일 상태를 보고.

**3 ) Hexa View**

&emsp;&emsp;**3-1) Hexa View 기능**
  - 파일의 바이너리 데이터를 헥사덤프(hexdump) 형식으로 출력하여 사용자가 쉽게 분석 가능.
  - 오프셋, 16진수 값, 디코드 텍스트를 정렬하여 표시하며, 가독성을 위해 오프셋은 파란색, 나머지는 기본 색상으로 표시.
  - QDockWidget 기반의 Hexa View 도킹 위젯을 제공.

&emsp;&emsp;**3-2) 텍스트 선택 및 강조 기능**
  - 마우스 드래그로 선택한 헥사 값(16진수)과 해당 디코드 텍스트를 서로 연동하여 강조 표시.
  - 헥사 값은 파란 배경과 흰색 텍스트로, 디코드 텍스트는 연한 파란색 배경으로 시각화.
  - 드래그 해제 시 선택 영역을 초기화하고 기본 텍스트 색상으로 복원.

&emsp;&emsp;**3-3) 주요 기능 및 인터랙션**
  - 마우스 클릭 및 드래그: 선택한 헥사 값과 디코드 텍스트를 하이라이트.
  - 자동 스크롤 초기화: 데이터를 처음부터 보기 쉽게 커서를 시작 위치로 이동.
  - UI 커스터마이징: 사용자 친화적이고 가독성을 높이기 위해 색상 및 폰트 설정.

&emsp;&emsp;**3-4) 도킹 기능**
  - 사용자는 도킹 패널의 위치를 자유롭게 변경하여 개인화된 분석 환경을 구성할 수 있음.
  - 분석 데이터와 Hexa View 연동 : 
    - 분석 결과 테이블(Detection Results)와 Hexa View가 연동되어 데이터 탐색과 세부 정보 확인이 원활하게 이루어짐.
    - 사용자가 테이블의 항목을 클릭하면 Hexa View에서 관련 데이터를 자동으로 표시.
  - 파일 선택 및 Hexa View 연동 기능 : 
    - 분석 결과 테이블에서 특정 파일 이름을 클릭하면, Hexa View와 연동되어 해당 파일의 헥사 값(16진수 데이터)를 자동으로 탐지.
    - 선택된 파일의 데이터와 관련된 헥사 값 영역이 강조 표시(마킹)되어 시각적 가독성을 높임. 
    => 이 기능은 분석 테이블과 헥사 뷰 간의 상호작용을 통해 데이터 추적 및 확인을 간소화함.

**4 ) 검색 기능**

&emsp;&emsp;**4-1) 검색 기능**
  - 상단에 배치된 검색창(QLineEdit), 검색 옵션(QComboBox), 검색 버튼, 클리어 버튼을 통해 분석 결과를 필터링.
  - 오프셋, 16진수 값, 디코드 텍스트를 정렬하여 표시하며, 가독성을 위해 오프셋은 파란색, 나머지는 기본 색상으로 표시.
  - QDockWidget 기반의 Hexa View 도킹 위젯을 제공.

&emsp;&emsp;**4-2) 분석 결과 테이블**
  - 분석 결과는 "와이핑", "완전 삭제", "데이터 위변조"의 세 가지 카테고리로 구분되어 표시.
  - 각 카테고리에 대해 별도의 테이블(QTableWidget)을 생성하며, 다음과 같은 열 구성을 가짐:
    - 와이핑: 와이핑된 파일 이름, 와이핑 흔적.
    - 완전 삭제: 파일명, 삭제 유형, 삭제 시간.
    - 데이터 위변조: 파일명, 변조 가능성, 복구 경로, 시간.
  - 테이블은 읽기 전용으로 설정하며, 사용자는 각 카테고리 버튼을 클릭하여 테이블 간에 전환 가능.

&emsp;&emsp;**4-3) 사용자 인터랙션**
  - 검색 옵션은 카테고리에 따라 동적으로 변경되며, 사용자는 원하는 데이터를 효율적으로 찾을 수 있음.
  - 테이블 열 크기는 데이터 크기에 따라 동적으로 조정되며, 긴 텍스트는 인터랙티브 모드로 제한된 너비로 표시.

&emsp;&emsp;**4-3) 결과 초기화 및 테이블 필터링**
  - "X" 버튼을 눌러 필터를 초기화하거나 모든 테이블 데이터를 한 번에 지우는 기능 제공.
  - 각 테이블은 행 단위로 숨기거나 표시하여 필터링 결과를 반영.

#### 마. 산업체 멘토링 의견 반영사항
&emsp;1 ) 피드백 1 : 문제의 필요성을 강조하고 솔루션 도출 과정을 스토리로 설명하고 사이버 보안 관련 사례나 기사로 발표 내용을 보완해라. 
심사하시는 분들이 모든 개념을 알고 있지 않다. 개념에 대해서 먼저 환기 후 도구의 필요성에 대해 설명하여 이목 끌기 & 초등학생을 이해시킨다는 마음으로 청자 고려하여 쉽게 설명하여 이해 시켜라. 
  > - 개념 설명을 더 쉽게 하려고 노력, 기사를 추가함
  > - 전달력이 부족했다고 생각. ( 포렌식에 대한 개념 부족한 청자 고려 부족 )

&emsp;2 ) 피드백 2 : 다른 포렌식 회사의 포렌식 방법은 어떤지 찾아봐라 ( 타 포렌식 업체와의 기법 차별성 중요 ). 
타 포렌식 업체와의 차별성을 강조하며 시장 조사와 독창성을 확보해라. 
UI를 직관적으로 개선하고, 플로우 차트로 개발 과정과 향후 계획을 시각적으로 표현하여라.
  > - 차별성 강조하여 발표
  > - 기대효과 및 활용 방안, 향후계획 소개함.
  > - 툴 브랜드명 강조, 검색버튼 수정, 인덱스 수정

&emsp;3 ) 피드백 3 : 해커톤마다 기술과 사업성의 우선순위가 다르므로 방향성을 설정해라. 새로 개발한 부분과 국내 유사 서비스 존재 여부를 확인하고 차별성과 필요성을 강조해라. 
툴 조사와 가격 차별화 방안을 마련하며, 심사위원을 초등학생이라 생각하고 쉽게 풀어서 설명해라
  > - 사업성 강조하고 툴 검색하여 타 툴 있는지 찾아봄
  > - 차별성 강조하여 발표
  > - 설명을 더 자세히 했어야 했다
